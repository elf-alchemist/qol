-----------------
Ultra-WiderPix854
-----------------



---------------------------------------------------------


This is a collection of 854 pixel wide widescreen assets by Meerschweinmann from Doomworld forum.


These assets are meant to use with monitors up to an aspect ratio of 32:9.
They are fine to use with 16:10, 16:9 and 21:9 monitors too.


The idea of this Project is to get rid of those black bars left and right on wider monitors.


Where to get latest version:
https://www.doomworld.com/forum/topic/148537


The assets are in PK3 format for GZDoom or in WAD format in an autoload file structure.

Weapons and widescreen pictures are in separate WADs.


The "Alternate_versions" folder contains different versions of the assets.
Examples:

- DOOM/Heretic registered with different titlescreens
- TNT with a slightly modified BOSSBACK screen that corrected some things or a separate CREDIT screen.
- Plutonia with a separate CREDIT screen.
 

The "Bunny_extended" folder is for developers only.

This WAD contains in the middle extended bunny-screens,
that are hopefully supported by some source port someday.
The idea is to fix the behavior that spiked Daisy scrolls to early
on screen (21:9) or is on screen before the picture scrolls (32:9).


The assets were tested with Crispy/International-DOOM, Woof, Eternity Engine, Odamex, Helion and GZDoom.


Have fun.

Meerschweinmann
